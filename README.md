# Accessible Responsive Portfolio

Ready-to-run static HTML5 portfolio.

## Run
Open `index.html` in any modern browser, or serve the folder with any static web server.

## Customize
1. Replace "My Portfolio" and placeholder copy.
2. Update canonical/OG URLs from `example.com`.
3. Replace project links (`#`).
4. Replace the contact email.
5. Add your own images under `assets/images/` and always provide useful alt text.
6. Connect `contact.html` to a real backend/form endpoint if messages need to be sent.

## Accessibility
Includes semantic HTML5 landmarks, skip link, keyboard focus states, accessible navigation, labelled form controls, live form status, reduced-motion support, and a light/dark theme.

## Lighthouse
The structure targets excellent Accessibility and SEO scores. Final Lighthouse results depend on deployed content, URLs, images, hosting, third-party resources and performance.
